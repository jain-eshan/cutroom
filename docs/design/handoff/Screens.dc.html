Render & publish

This is the screen that converts "an editor" into "a way to publish". It reframes Export from a button into a manifest — you see the full set of artefacts an episode actually needs before it can go out, with the two unbuilt ones (show notes, clips) sitting unchecked and honest rather than hidden. Destinations are opt-in per publish, which is the only place in the whole product where the local-first promise has an exception, so it says so out loud.
